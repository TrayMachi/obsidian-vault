# University Todo

Use `10 University/TODO.md` as the single university task dashboard.

- Group tasks under `## <Subject>` headings.
- Create the subject heading if it does not exist.
- Add tasks as Markdown checkboxes: `- [ ] <task>`.
- Keep task wording short and actionable.
- Include due dates or links only when the user provides them or they already exist in the vault.
- Do not create a separate detail note for a todo unless explicitly asked.
- When completed, change `[ ]` to `[x]` and leave it under the same subject.
- Do not invent subjects, deadlines, grades, or requirements.
