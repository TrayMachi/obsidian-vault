# Project Management

Store side projects under `40 Projects/<Project Name>/`.

- Create one folder per project.
- Use `90 Templates/Project.md` as a lightweight starting shape when useful.
- Keep project-specific todos, decisions, notes, and references inside the project folder.
- Prefer updating an existing project instead of creating a duplicate.
- Do not move Work or University material into Projects unless explicitly asked.
- Archive inactive or completed projects under `99 Archive/` only when asked.
