# University Notes

Store university notes under `10 University/Subjects/<Subject>/`.

- Create the subject folder when the first note for that subject is added.
- Create separate Markdown files for distinct lectures, topics, summaries, or references when useful.
- Use clear note names such as `Dynamic Programming.md` or `Week 3 - Concurrency.md`.
- Use `90 Templates/University Note.md` as a lightweight shape when helpful; do not force empty sections that add no value.
- Set `subject` to the actual subject when using frontmatter.
- Update an existing note instead of creating a duplicate when it is clearly the same topic.
- Preserve source links and connect related notes with Obsidian links when helpful.
- Do not invent course facts, deadlines, grades, or requirements.
